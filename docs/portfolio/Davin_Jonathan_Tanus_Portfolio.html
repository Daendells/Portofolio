Featured Projects — AI Products

RAG Assistant for the ITS Academic Regulation Live demo GitHub

Role: AI engineer · personal project · 57-page official regulation, 91 articles

  • Problem: students need exact answers from a long academic regulation, and an AI answer is only useful if it points to the article it came from.
  • Approach: OCR-tolerant chunking per Pasal and ayat; BM25 and multilingual-e5 embeddings fused by reciprocal rank fusion; the LLM must cite retrieved passages and the server drops any other citation; quantised ONNX runtime without PyTorch (about 285 MB of RAM); FastAPI, Docker, pytest, and CI that fails if retrieval drops.
  • Outcome: on a frozen 70-question set, retrieval MRR 0.84 against 0.80 for keywords alone, and all 10 questions outside the regulation refused; a hand check of the LLM judge is published with the failure cases.
  • RAG
  • Hybrid Search
  • LLM Evaluation
  • FastAPI
  • ONNX

BISINDO Fingerspelling — In-Browser Sign Language Recognition Live demo GitHub

Role: ML engineer & front-end · personal project · 26 letters, on-device

  • Problem: read the Indonesian Sign Language alphabet from a webcam without a server, and know how far the accuracy can be trusted.
  • Approach: audited the public dataset (63% of validation images were near-copies of training images) and re-split by perceptual-hash groups; fine-tuned YOLO11n, chose on validation only, exported to ONNX and ran it client-side with ONNX Runtime Web plus an 8-frame vote.
  • Outcome: 98.5% on a held-out test set (scored once) and 93.6% on an unseen signer; every error there falls on O or Y, and the failure analysis is published on the live demo page.
  • YOLO11
  • PyTorch
  • ONNX Runtime Web
  • Data Leakage Audit

Featured Projects — Machine Learning

Indonesian App Review Sentiment Analysis Training notebook Case study

Role: ML engineer · Dicoding NLP project · 16,000+ self-scraped reviews

  • Problem: distill thousands of Indonesian app reviews into product signal (positive / neutral / negative).
  • Approach: slang normalization, sentiment-aware preprocessing, deduplication, class balancing; benchmarked LinearSVC, logistic regression, and a PyTorch BiLSTM with per-class and confusion-matrix analysis.
  • Outcome: 92.17% test accuracy with a repeatable inference module.
  • NLP
  • Scikit-Learn
  • PyTorch BiLSTM
  • Text Classification

Multi-Class Image Classification with On-Device Export Training notebook Case study

Role: ML engineer · Dicoding deep-learning project

  • Problem: accurate image recognition that can run beyond the lab — server, mobile, and browser.
  • Approach: MobileNetV2 transfer learning on 13,394 Imagenette images (10 classes, 80/10/10 split), augmentation, staged fine-tuning, checkpointing; evaluated with learning curves, confusion matrix, per-class metrics.
  • Outcome: 91.67% test accuracy; model exported to SavedModel, TensorFlow Lite (mobile), and TensorFlow.js (browser).
